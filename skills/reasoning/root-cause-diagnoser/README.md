# 🔍 Root Cause Diagnoser

Uncover deep systemic root causes behind outages and chronic bugs using structured causal analysis.

## What it does

Guides deep diagnostic investigations using the 5-Whys and causal chain methodologies to ensure teams fix systemic vulnerabilities, not just symptoms.

## When to use it

- After production outages and security incidents.
- When addressing recurring, intermittent bugs.
- Preparing blameless postmortems.

## Best for

- Incident postmortems
- Stability engineering
- CI/CD quality enforcement
- Architecture resilience

## Example usage

> "Diagnose why our billing webhook silently failed for 3 hours after a database schema migration."

## Expected output

A rigorous 5-Whys chain and concrete preventive controls targeting architecture, testing, and alerting.
