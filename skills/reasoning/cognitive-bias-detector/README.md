# 🧠 Cognitive Bias Detector

Identify subtle cognitive traps in engineering proposals, estimates, and architectural debates.

## What it does

Scans project plans and architecture debates for common thinking biases (sunk cost, anchoring, optimism bias, not-invented-here syndrome) and provides objective re-framing.

## When to use it

- Reviewing aggressive project deadlines and estimations.
- Debating migrations away from legacy internal tools.
- Evaluating architectural proposals for hidden assumptions.

## Best for

- Project scoping and roadmapping
- Technical debates
- Architecture reviews
