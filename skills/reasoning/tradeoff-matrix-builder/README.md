# ⚖️ Tradeoff Matrix Builder

Construct rigorous, weighted evaluation matrices for comparing technical choices.

## What it does

Transforms subjective technology debates into structured, objective decision matrices with clear weighting, scoring rationale, and risk evaluations.

## When to use it

- Picking an ORM, state library, database, or cloud provider.
- Authoring RFC decision sections.
- Aligning engineering stakeholders.

## Best for

- Tech stack evaluation
- RFC and ADR decision making
- Buy vs. Build analysis

## Example usage

> "Build a tradeoff matrix comparing Prisma, Drizzle, and Kysely for a high-throughput Next.js app with Postgres."
