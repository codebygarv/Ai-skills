# 🌊 Second-Order Effects Analyzer

Map downstream ripple effects, feedback loops, and unintended consequences of technical changes.

## What it does

Looks beyond immediate first-order results to evaluate how changes will impact other microservices, database contention, and human user behavior over time.

## When to use it

- Planning API rate limits or quota reductions.
- Deprecating legacy endpoints or features.
- Introducing caching, retries, or database connection pool limits.

## Best for

- Systems thinking & risk analysis
- Architecture impact assessments
- Unintended consequence prevention
