# ❓ Socratic Interrogator

Probe ambiguous specifications and unpack hidden assumptions with structured inquiry.

## What it does

Dissects vague feature requests and user stories by asking targeted Socratic questions, surfacing hidden requirements before engineering work begins.

## When to use it

- Clarifying underspecified Jira/Linear tickets.
- Sprint planning and requirement refinement sessions.
- Designing API contracts with ambiguous business rules.

## Best for

- Requirements discovery
- Sprint refinement & scoping
- Edge case exploration
