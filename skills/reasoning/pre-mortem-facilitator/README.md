# 🔮 Pre-Mortem Facilitator

Assume your project failed 6 months from now, then work backward to find why.

## What it does

Facilitates an adversarial pre-mortem exercise that breaks through groupthink and optimistic bias to uncover catastrophic failure modes before writing code or launching.

## When to use it

- Major system migrations or database cutovers.
- New microservice or public API launches.
- Critical architectural changes.

## Best for

- Risk management
- Launch readiness
- Architecture review
