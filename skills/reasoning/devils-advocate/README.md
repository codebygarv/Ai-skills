# ⚖️ Devil's Advocate

Argue the other side, properly.

## What it does

Takes whatever position or decision you've stated and builds the strongest honest case against it — real supporting evidence, anticipated rebuttals, and an honest verdict on how strong the counter-case actually is.

## When to use it

- You've settled on a decision and want to know the best argument against it before you commit.
- A team is converging on consensus faster than the decision deserves.
- You want to test a position, not just get feedback on it.

## Best for

- Strategic/product decisions
- "Build vs. buy" calls
- Process or policy changes
- Any decision made by consensus that hasn't been argued against

## Example usage

> "Play devil's advocate: we've decided to rewrite the frontend in a new framework."

## Expected output

A single coherent counter-position (not a scattershot list of complaints), with supporting evidence, an anticipated rebuttal and response, and an honest closing verdict on how strong the counter-case actually is.

## Limitations

- It won't manufacture a strong counter-argument where none exists — if the original decision is genuinely sound, the verdict will say so rather than inventing false balance.
- It argues one coherent position, not every possible objection — pair with GrillMe for broader stress-testing.
