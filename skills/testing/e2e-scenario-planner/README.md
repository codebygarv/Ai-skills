# 🎭 E2E Scenario Planner

Plan and architect fast, reliable End-to-End tests with Playwright and Cypress.

## What it does

Designs high-confidence E2E test suites for critical user flows with robust locator strategies, shared auth states, and parallel execution.

## When to use it

- Setting up Playwright or Cypress for web apps.
- Reducing flakiness in existing E2E test suites.
- Protecting revenue-critical user conversion flows.

## Best for

- Playwright & Cypress test suites
- Critical User Journeys (CUJs)
- Page Object Model architecture
