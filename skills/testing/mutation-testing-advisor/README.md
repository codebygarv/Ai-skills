# 🧬 Mutation Testing Advisor

Uncover blind spots in your test suite where code can be mutated without causing test failures.

## What it does

Analyzes test assertions against synthetic code mutations to reveal weak tests, missing boundary checks, and illusory code coverage.

## When to use it

- Auditing safety-critical modules (payment calculation, authorization).
- Investigating why high-coverage code broke in production.
- Setting up Stryker or mutation testing tooling.

## Best for

- Test suite hardening
- Stryker, Mutmut, PIT
- True test quality vs vanity coverage
