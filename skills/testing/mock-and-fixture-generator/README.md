# 🎭 Mock and Fixture Generator

Generate realistic, edge-case-rich mock data fixtures without PII exposure.

## What it does

Constructs synthetic test datasets and mock factories containing diverse data, boundary values, and relational consistency for robust testing.

## When to use it

- Seeding local databases and unit test fixtures.
- Mocking external third-party API payloads (Stripe, GitHub, Salesforce).
- Frontend mock servers (MSW).

## Best for

- Test fixtures & Mock Service Worker (MSW)
- Factory functions & Synthetic data
- Privacy-safe test databases
