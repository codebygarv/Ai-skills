# 📈 Load Test Scenario Builder

Build realistic load and stress testing scripts with k6 and Locust.

## What it does

Generates comprehensive performance test scripts modeling multi-step user behaviors, traffic ramp-up stages, and automated SLO pass/fail gates.

## When to use it

- Pre-launch capacity planning.
- CI/CD automated performance regression testing.
- Benchmarking API latency under concurrent load.

## Best for

- k6, Locust, JMeter, Autocannon
- Load & stress testing
- Latency percentile benchmarking (p95, p99)
