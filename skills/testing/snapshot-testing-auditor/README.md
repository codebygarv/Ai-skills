# 📸 Snapshot Testing Auditor

Eliminate brittle snapshot tests and false CI alarms with resilient semantic assertions.

## What it does

Audits test suites to replace massive, fragile DOM/JSON snapshots with robust semantic queries that survive UI refactors.

## When to use it

- Fixing test suites where developers blindly run `jest -u`.
- Reducing CI test breakage during CSS and UI refactorings.
- Hardening React Testing Library and Vitest test suites.

## Best for

- Snapshot testing hygiene
- Jest, Vitest, React Testing Library
- Flaky test reduction
