# 📜 Contract Testing Designer

Design consumer-driven contract tests with Pact to prevent breaking API changes.

## What it does

Establishes automated contract tests that verify frontend-backend and service-to-service compatibility independently in CI.

## When to use it

- Decoupling microservice test pipelines.
- Verifying public and private API contracts.
- Eliminating fragile integrated staging environments.

## Best for

- Pact, Spring Cloud Contract
- Microservice integration safety
- OpenAPI contract testing
