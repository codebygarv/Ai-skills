# 🌪️ Chaos Experiment Designer

Design controlled chaos engineering experiments to validate cloud resilience and automated failover.

## What it does

Structures turbulence experiments (network delay, packet drops, instance terminations) with strict steady-state hypotheses and safety abort triggers.

## When to use it

- GameDay preparations and disaster recovery drills.
- Testing circuit breakers, timeouts, and fallback caches.
- Chaos Mesh, LitmusChaos, and AWS Fault Injection Simulator setups.

## Best for

- Chaos engineering & SRE
- Resilience testing
- Circuit breaker validation
