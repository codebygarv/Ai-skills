# 🏛️ ADR Generator

Draft formal Architecture Decision Records (ADR) to preserve technical context and rationale.

## What it does

Structures technical decisions into clean, standardized Architecture Decision Records capturing context, alternatives, and trade-offs.

## When to use it

- Recording major technical choices and migrations.
- Standardizing team documentation practices.
- Explaining architectural shifts in code reviews.

## Best for

- Architecture Decision Records (ADRs)
- System design documentation
- Engineering team alignment
