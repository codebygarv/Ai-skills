# 📚 Codebase Glossary Builder

Build a unified domain dictionary and ubiquitous language guide from your codebase.

## What it does

Extracts and defines complex business terms, domain concepts, and acronyms across a repository to eliminate ambiguity for engineers and stakeholders.

## When to use it

- Onboarding developers into domain-heavy industries (Fintech, EdTech, Healthcare).
- Aligning DDD ubiquitous language across product and engineering.
- Resolving conflicting naming conventions in legacy code.

## Best for

- Domain-Driven Design (DDD)
- Engineering onboarding
- Business logic documentation
