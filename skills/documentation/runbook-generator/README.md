# 📖 Runbook Generator

Create copy-pasteable, battle-ready operational runbooks for on-call teams.

## What it does

Drafts structured, step-by-step incident response runbooks designed for high-stress on-call situations, complete with exact diagnostic commands and mitigation steps.

## When to use it

- Documenting responses to Datadog/Prometheus alert triggers.
- Disaster recovery and failover SOPs.
- Onboarding new engineers to on-call rotations.

## Best for

- SRE & DevOps runbooks
- Incident triage & mitigation
- On-call playbooks
