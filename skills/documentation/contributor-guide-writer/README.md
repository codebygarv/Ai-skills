# 🤝 Contributor Guide Writer

Create welcoming, clear CONTRIBUTING.md guides and GitHub PR templates for open-source repos.

## What it does

Drafts end-to-end contributor guides with step-by-step local development setup instructions, code style standards, and PR submission templates.

## When to use it

- Preparing a repository for open-source release.
- Reducing friction for first-time external contributors.
- Enforcing consistent PR descriptions and testing standards.

## Best for

- Open-source repository maintenance
- CONTRIBUTING.md & PR templates
- Developer onboarding documentation
