# 📢 Release Notes Writer

Transform technical commit histories into clear, customer-friendly product release notes.

## What it does

Converts raw PR logs and technical changes into engaging changelogs and release notes that communicate real user value.

## When to use it

- Shipping new versions, npm releases, or SaaS updates.
- Writing App Store / Play Store update text.
- Publishing public customer changelogs.

## Best for

- Product release notes
- Developer changelogs
- App Store release descriptions
