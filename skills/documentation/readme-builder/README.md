# 📄 README Builder

A professional README, grounded in your actual project.

## What it does

Generates a complete README — what it does, installation, usage, configuration, contributing, license — using the real commands and structure from your project's manifest/scripts, not invented ones.

## When to use it

- A repo has no README, or a thin/outdated one.
- Preparing a project for public release or wider sharing.
- You want a README that's skimmable in under a minute for the essentials.

## Best for

- New open-source or internal project READMEs
- Refreshing a stale README against the current codebase
- Making an install/usage flow that's actually accurate

## Example usage

> "Build a README for this project" (point to the repo/package manifest, or paste key files)

## Expected output

A complete README.md with title, description, installation, usage example, configuration (if applicable), contributing, and license sections — scaled to the project's actual maturity.

## Limitations

- Only as accurate as the source it's given — verify install/run commands against the actual manifest before publishing.
- Won't invent badges (CI status, coverage, npm version) that don't correspond to something real in the project.
