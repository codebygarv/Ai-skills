# 📝 RFC Proposal Writer

Draft structured, consensus-building Request for Comments (RFC) technical proposals.

## What it does

Structures engineering proposals into rigorous RFC documents covering technical architecture, security, trade-offs, and rollout phases.

## When to use it

- Proposing major architectural investments or migrations.
- Driving technical alignment across multiple engineering squads.
- Presenting technical designs for review and sign-off.

## Best for

- Engineering RFCs & Design Docs
- Cross-team technical proposals
- Architecture planning
