# 📄 OpenAPI Spec Generator

Generate valid, expressive OpenAPI 3.1 / Swagger documentation from application routes and schemas.

## What it does

Converts backend route handlers, Zod schemas, and data models into complete OpenAPI 3.1 specifications ready for Swagger UI and SDK generation.

## When to use it

- Documenting REST APIs for public or internal developer portals.
- Integrating with Swagger UI, Redoc, or Scalar.
- Generating client SDKs with openapi-generator.

## Best for

- OpenAPI 3.1 & Swagger specs
- Zod / Pydantic schema export
- Interactive API documentation
