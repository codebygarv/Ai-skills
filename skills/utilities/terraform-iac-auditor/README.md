# 🏗️ Terraform IaC Auditor

Audit Terraform and OpenTofu infrastructure modules for security, least privilege, and state safety.

## What it does

Inspects Terraform HCL files to eliminate open security groups, excessive IAM permissions, unencrypted storage, and missing state locks.

## When to use it

- Writing and reviewing Terraform / OpenTofu modules.
- Passing Checkov and tfsec compliance scans.
- Hardening AWS, GCP, and Azure cloud infrastructure.

## Best for

- Terraform & OpenTofu
- Infrastructure-as-Code (IaC) security
- Cloud compliance (AWS, GCP, Azure)
