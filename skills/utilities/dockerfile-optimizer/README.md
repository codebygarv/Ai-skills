# 🐳 Dockerfile Optimizer

Shrink container sizes, speed up build layer caching, and harden container security.

## What it does

Transforms bloated, slow Dockerfiles into lean, multi-stage, non-root production container images.

## When to use it

- Slashing container image sizes and CI push/pull times.
- Eliminating Trivy/Snyk security vulnerabilities in container images.
- Optimizing Node.js, Go, Rust, or Python Dockerfiles.

## Best for

- Docker & container optimization
- Multi-stage builds & Distroless images
- Container security hardening
