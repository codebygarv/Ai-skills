# 🏷️ SemVer Bump Advisor

Determine exact Semantic Versioning bumps (MAJOR / MINOR / PATCH) from git changes.

## What it does

Audits commit diffs and exported API surfaces against SemVer 2.0.0 rules to recommend the precise version bump and highlight breaking changes.

## When to use it

- Publishing npm, PyPI, or Go packages.
- Setting up automated semantic-release pipelines.
- Auditing PRs for accidental API breaking changes.

## Best for

- Semantic Versioning (SemVer 2.0.0)
- Package publishing & release automation
- Breaking change detection
