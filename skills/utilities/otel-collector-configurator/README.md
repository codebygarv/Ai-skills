# 🔭 OpenTelemetry Collector Configurator

Design production-grade OpenTelemetry Collector pipelines for traces, metrics, and logs.

## What it does

Generates optimized OpenTelemetry Collector configurations with memory limiters, PII redaction processors, and multi-destination exporters.

## When to use it

- Setting up OpenTelemetry (OTel) infrastructure.
- Routing telemetry to Prometheus, Tempo, Datadog, or SigNoz.
- Scrubbing sensitive data and filtering health check trace noise.

## Best for

- OpenTelemetry (OTel) Collector
- Distributed tracing, metrics & logs
- Observability pipeline architecture
