# ☸️ Helm and K8s Manifest Reviewer

Review Kubernetes manifests and Helm charts for security, resource limits, and probe safety.

## What it does

Audits Kubernetes resources against production reliability standards, ensuring zero-downtime rolling updates and security context compliance.

## When to use it

- Deploying new services to EKS, GKE, or AKS.
- Writing or refactoring Helm chart templates.
- Resolving pod eviction and traffic dropping bugs during deployments.

## Best for

- Kubernetes (K8s) manifests & Helm charts
- Pod security standards & probes
- Production readiness audits
