# 🗜️ Context Window Optimizer

Condense codebase context and prompt inputs for maximum LLM efficiency and accuracy.

## What it does

Extracts high-signal code skeletons, type signatures, and compressed error traces to fit maximum intelligence into limited LLM context windows.

## When to use it

- Preparing large repositories for AI agent ingestion.
- Debugging huge multi-megabyte log files with LLMs.
- Reducing token costs and latency in automated LLM pipelines.

## Best for

- Prompt engineering & context curation
- LLM token optimization
- Code skeleton extraction
