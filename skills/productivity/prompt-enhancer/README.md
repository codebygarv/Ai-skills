# 🎯 Prompt Enhancer

Transform vague, unstructured prompts into high-precision, constraint-driven instructions.

## What it does

Structures raw requests into high-performing prompts with explicit roles, clear execution directives, negative constraints, and structured output formats.

## When to use it

- Refining prompts that yield disappointing or hallucinated outputs.
- Building agent skills and system prompts.
- Designing zero-shot and few-shot LLM templates.

## Best for

- Prompt engineering & refinement
- System prompt design
- Agent instruction structuring
