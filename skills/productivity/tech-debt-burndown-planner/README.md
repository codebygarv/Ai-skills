# 📉 Tech Debt Burndown Planner

Quantify, prioritize, and systematically burn down technical debt with clear ROI metrics.

## What it does

Transforms vague complaints about legacy code into an objective, ranked technical debt backlog that product and engineering teams can prioritize together.

## When to use it

- Planning quarterly engineering health sprints.
- Justifying refactorings to product managers.
- Eliminating slow CI builds, flaky tests, and dependency rot.

## Best for

- Tech debt prioritization
- Engineering health OKRs
- Developer velocity improvement
