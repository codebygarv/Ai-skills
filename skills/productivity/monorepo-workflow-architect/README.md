# 📦 Monorepo Workflow Architect

Architect fast, modular monorepos with Turborepo, Nx, and pnpm workspaces.

## What it does

Structures scalable multi-package monorepos with shared type libraries, unified config presets, and remote build artifact caching.

## When to use it

- Structuring Turborepo, Nx, or pnpm monorepos.
- Sharing UI components, utilities, and types across apps.
- Configuring task pipelines and remote caching in CI.

## Best for

- Turborepo & Nx workspace architecture
- pnpm / npm workspaces
- Shared component & config package design
