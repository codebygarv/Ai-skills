# ⚡ CI/CD Pipeline Optimizer

Accelerate GitHub Actions and GitLab CI workflows with intelligent caching and parallelization.

## What it does

Audits CI/CD pipelines to eliminate redundant steps, configure robust multi-layer caching, and parallelize slow test suites.

## When to use it

- Speeding up slow 15+ minute pull request checks.
- Slashing GitHub Actions / CI compute costs.
- Implementing test sharding and Docker build layer caching.

## Best for

- GitHub Actions, GitLab CI, CircleCI optimization
- Docker buildx layer caching
- Test sharding & matrix builds
