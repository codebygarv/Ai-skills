# 🔀 Git Conflict Resolver

Resolve complex git rebase and merge conflicts while preserving intent from both branches.

## What it does

Analyzes tangled git conflict markers with semantic AST context, combining changes from both branches without introducing silent regressions or broken imports.

## When to use it

- Rebasing long-lived feature branches onto main.
- Resolving conflicting package dependencies and lockfiles.
- Reconciling simultaneous code refactors.

## Best for

- Git conflict resolution
- Rebase & merge reconciliation
- Lockfile conflict recovery
