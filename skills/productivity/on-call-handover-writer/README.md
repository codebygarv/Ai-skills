# 🔄 On-Call Handover Writer

Format structured, actionable end-of-shift handover reports for engineering teams.

## What it does

Summarizes on-call shift activity, active incident statuses, alert noise candidates, and upcoming risks for seamless rotation transitions.

## When to use it

- On-call rotation changeovers.
- Follow-the-sun global engineering handovers.
- On-call health and alert volume reviews.

## Best for

- SRE & DevOps rotations
- Incident handover & continuity
- Alert tuning documentation
