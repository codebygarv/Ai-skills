# 🔄 Retro Facilitator

Turn sticky notes into themes and actions that actually happen.

## What it does

Clusters raw retro input (went well / went poorly / to try) into coherent themes, and converts the significant ones into concrete, ownable action items — instead of a flat list of every individual complaint.

## When to use it

- After a sprint/iteration retro, with raw notes that need structuring.
- Retros tend to surface the same complaints repeatedly with no visible action.

## Best for

- Post-retro summaries
- Clustering scattered feedback into actionable themes
- Surfacing recurring issues that keep coming back unaddressed

## Example usage

> "Structure this retro: [raw went-well/went-poorly/to-try notes]"

## Expected output

Clustered Went Well / Went Poorly / Ideas to Try sections, and an Action Items table (owner if assigned, related theme) — with recurring themes flagged if prior-retro context is given.

## Limitations

- Won't invent an owner for an action item that wasn't assigned in the retro itself.
- Clustering quality depends on how much raw context is given — very terse notes ("meetings bad") give less to work with than fuller sentences.
