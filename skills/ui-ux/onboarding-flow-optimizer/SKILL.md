## Purpose

Design high-conversion, low-friction user onboarding workflows that minimize cognitive load, eliminate premature form fields, and accelerate users to their first "Aha!" moment.

## When to Use

- Designing user sign-up, setup wizards, and workspace creation.
- High drop-off rates during initial user onboarding.
- Deciding which questions are mandatory upfront vs deferrable via progressive disclosure.

## What to Analyze

1. **Time-to-Value (TTV)**: How many clicks and seconds before the user experiences core product value?
2. **Form Friction**: Eliminate fields that can be defaulted, inferred from OAuth/IP, or asked later.
3. **Progressive Disclosure**: Show advanced settings only when contextually relevant.
4. **Progress Indicators**: Multi-step wizard meters with clear milestone validation.
5. **Interactive Templates vs Blank Canvas**: Providing starter templates rather than an empty workspace.

## Output Format

- **Onboarding Journey Map**: Step-by-step screen breakdown with eliminated friction points.
- **Progressive Form Strategy**: Mandatory fields vs Postponed fields.
- **Empty-to-Productive Transition**: Sample starter template / checklist design.

## Avoid

- Forcing 15-question demographic surveys before the user can touch the product.
- Blocking sign-up with email verification before allowing a user to explore a demo workspace.
