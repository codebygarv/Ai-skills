# 🚀 Onboarding Flow Optimizer

Reduce user drop-off and accelerate time-to-value with frictionless onboarding designs.

## What it does

Audits and structures onboarding wizards, sign-up flows, and first-run experiences to get users to core value quickly.

## When to use it

- Designing new user registration and team setup.
- Optimizing low trial-to-activation conversion rates.
- Implementing progressive disclosure in complex enterprise tools.

## Best for

- Product onboarding & activation
- Wizard UI/UX
- Growth and conversion optimization
