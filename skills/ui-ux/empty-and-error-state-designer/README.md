# 📭 Empty and Error State Designer

Design actionable zero-data states, 404 screens, and helpful error recovery interfaces.

## What it does

Turns blank slates and error boundaries into intuitive guides that instruct users on what to do next with clear CTAs and reassuring copy.

## When to use it

- First-time onboarding views.
- Search result pages with zero matches.
- Application error boundary screens.

## Best for

- UI/UX empty states
- Error boundaries & 404 screens
- User onboarding guidance
