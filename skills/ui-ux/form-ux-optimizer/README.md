# 📝 Form UX Optimizer

Design accessible, high-conversion web forms with smart validation timing and mobile auto-fill.

## What it does

Eliminates form friction, aggressive validation errors, and mobile typing pain by implementing standard autocomplete tokens, accessible ARIA descriptions, and "reward early, punish late" validation logic.

## When to use it

- Checkout and signup form optimization.
- Resolving accessible form validation issues.
- Fixing mobile keyboard layout and auto-fill problems.

## Best for

- Web form UI/UX & conversion rate optimization
- React Hook Form / Formik architecture
- WCAG form accessibility & ARIA bindings
