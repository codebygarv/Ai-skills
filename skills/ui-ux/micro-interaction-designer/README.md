# ✨ Micro-Interaction Designer

Craft smooth, responsive UI animations, state transitions, and spring physics.

## What it does

Designs purposeful micro-interactions and motion physics that make web and mobile applications feel tactile, alive, and ultra-responsive.

## When to use it

- Adding polish to buttons, cards, modals, and navigation.
- Implementing Framer Motion or CSS keyframe animations.
- Ensuring compliance with reduced-motion preferences.

## Best for

- UI polish and micro-animations
- Framer Motion, CSS transitions
- Design system interaction states
