# 🎨 Color Palette Generator

Generate accessible, semantic color token systems with guaranteed WCAG compliance for light and dark modes.

## What it does

Constructs complete design system color palettes, mapping raw hues into functional semantic tokens with verified contrast ratios.

## When to use it

- Creating a new design system or styling architecture.
- Adding dark mode support.
- Resolving WCAG accessibility contrast issues.

## Best for

- CSS custom properties & Tailwind themes
- Dark mode architecture
- WCAG AA/AAA compliance
