# 📋 SOC 2 Evidence Collector

Automate compliance evidence gathering for SOC 2 Type II audits across security and change controls.

## What it does

Structures and extracts audit-ready evidence for SOC 2 Trust Services Criteria, covering change management, access control, encryption, and disaster recovery drills.

## When to use it

- Preparing for SOC 2 Type I or Type II audits.
- Integrating with compliance platforms (Vanta, Drata).
- Documenting engineering security controls for enterprise RFPs.

## Best for

- SOC 2 Type II compliance
- Change management audit trails
- Security evidence automation
