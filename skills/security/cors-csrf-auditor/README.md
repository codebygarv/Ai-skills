# 🔒 CORS and CSRF Auditor

Audit web applications for cross-origin security flaws, unsafe CORS reflection, and CSRF vulnerabilities.

## What it does

Evaluates CORS headers, SameSite cookie attributes, and anti-CSRF token mechanisms to protect user sessions from cross-site exploitation.

## When to use it

- Setting up cross-domain API communication.
- Reviewing authentication cookies and preflight headers.
- Security vulnerability remediation.

## Best for

- CORS & CSRF security audits
- Cookie configuration & SameSite hardening
- Web application security
