# 🕵️ Data Anonymizer Specifier

Define PII redaction and data masking rules for safe logs and staging environments.

## What it does

Establishes masking, pseudonymization, and synthetic data replacement pipelines to prevent PII and credentials from leaking into telemetry or staging databases.

## When to use it

- GDPR, HIPAA, and PCI-DSS compliance audits.
- Creating sanitized staging database dumps.
- Hardening loggers against accidental secret leakage.

## Best for

- PII redaction & log scrubbing
- Database sanitization scripts
- Privacy engineering & GDPR compliance
