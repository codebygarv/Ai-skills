# 🔐 Cryptographic Practices Auditor

Audit applications for weak ciphers, insecure RNGs, and timing attack vulnerabilities.

## What it does

Reviews encryption implementations, password hashing, and token signatures against modern NIST and OWASP cryptographic standards.

## When to use it

- Auditing password storage and user authentication logic.
- Implementing webhook signature validation.
- Verifying encryption at rest and in transit.

## Best for

- Cryptography & key security
- Password hashing (Argon2 / bcrypt)
- Timing-safe HMAC validation
