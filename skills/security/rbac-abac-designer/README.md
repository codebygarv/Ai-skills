# 🛡️ RBAC and ABAC Designer

Design enterprise Role-Based and Attribute-Based Access Control systems with strict tenant isolation.

## What it does

Architects fine-grained permission models, role hierarchies, and multi-tenant security policies to prevent authorization bypasses.

## When to use it

- Adding team roles and permissions to a SaaS app.
- Implementing ABAC policy engines (Casbin, OPA/Cedar).
- Preventing IDOR vulnerabilities in multi-tenant databases.

## Best for

- RBAC, ABAC, ReBAC authorization
- Multi-tenant data isolation & Postgres RLS
- SaaS permissions architecture
