# 🚀 Zero-Downtime Migration Planner

Plan flawless database schema changes and service cutovers without maintenance windows.

## What it does

Designs multi-phase Expand-and-Contract migrations, non-blocking DDL scripts, and canary deployment pipelines for 24/7 uptime systems.

## When to use it

- Renaming, dropping, or restructuring database columns.
- Microservice rewrites and protocol migrations.
- High-availability cloud cutovers.

## Best for

- Expand and Contract database migrations
- Canary & Blue-Green deployments
- High-availability system upgrades
