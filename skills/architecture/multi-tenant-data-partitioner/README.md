# 🏢 Multi-Tenant Data Partitioner

Architect secure, scalable database multi-tenancy models with Postgres Row-Level Security and tenant routing.

## What it does

Guides the selection and implementation of multi-tenant database architectures (Shared DB vs Separate Schema vs Silo) with strict isolation policies.

## When to use it

- Building B2B multi-tenant SaaS platforms.
- Enforcing Postgres Row-Level Security (RLS).
- Isolating enterprise customer data for compliance.

## Best for

- Multi-tenant architecture & SaaS design
- Postgres Row-Level Security (RLS)
- Tenant connection routing & isolation
