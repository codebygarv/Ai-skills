# 🏰 Microservices Boundary Definer

Decompose monolithic systems into clean, decoupled domain services using Strategic Domain-Driven Design.

## What it does

Defines high-cohesion microservice boundaries, bounded contexts, and domain event communication channels to prevent distributed monoliths.

## When to use it

- Planning a monolith-to-microservices migration.
- Reviewing service responsibilities and preventing shared database coupling.
- Aligning engineering teams to autonomous software boundaries.

## Best for

- Domain-Driven Design (DDD)
- Microservices architecture
- Monolith extraction
