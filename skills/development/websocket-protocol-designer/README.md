# 🔌 WebSocket Protocol Designer

Design production-grade real-time WebSocket and SSE protocols with heartbeat management and message replay.

## What it does

Architects resilient real-time protocols with standard message envelopes, dead-connection detection, and reconnection catch-up buffers.

## When to use it

- Building real-time chat, notifications, and live dashboards.
- Replacing polling endpoints with WebSockets or Server-Sent Events.
- Designing reconnect logic and socket authentication.

## Best for

- WebSockets, SSE, Socket.io, ws
- Real-time messaging architecture
- Connection resilience & keep-alives
