# ⚡ Resilience Circuit Breaker Designer

Prevent cascading service outages with circuit breakers, bulkheads, and fallback policies.

## What it does

Designs defensive resilience architectures to isolate slow or failing third-party APIs, protecting application connection pools from thread starvation.

## When to use it

- Integrating third-party APIs and microservice clients.
- Preventing cascading latency in microservice meshes.
- Designing graceful fallbacks and bulkhead concurrency limits.

## Best for

- Circuit breakers (Opossum, Resilience4j, Polly)
- Bulkhead isolation & timeouts
- High-availability microservices
