# 🕸️ GraphQL Schema Designer

Design production-grade, evolvable GraphQL APIs with standard pagination, error unions, and DataLoader batching.

## What it does

Drafts GraphQL schemas following Relay Cursor Connection specs, strict input/payload mutation patterns, and N+1 resolver mitigations.

## When to use it

- Building new GraphQL APIs or Apollo/Yoga servers.
- Adding complex nested relationship queries.
- Designing robust mutation contracts with typed domain errors.

## Best for

- GraphQL schema design
- Apollo Server, Yoga, Nexus, Pothos
- N+1 DataLoader architecture
