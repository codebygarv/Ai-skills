# 🧬 Legacy Code Refactorer

Untangle and modernize fragile legacy code safely using the Mikado Method and characterization tests.

## What it does

Provides structured, low-risk refactoring roadmaps for tightly coupled legacy code, establishing safety-net characterization tests and dependency-free incremental PRs.

## When to use it

- Refactoring un-tested legacy spaghetti code.
- Breaking apart monolithic God classes.
- Modernizing legacy callback code to async/await and dependency injection.

## Best for

- Legacy code modernization
- Mikado Method & Strangler Fig
- Characterization (Golden Master) testing
